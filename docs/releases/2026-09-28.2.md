# Naufal Windows Utility v8.0.0.0 — SMART and Documentation Refresh

Build: **20260928.2** (28 September 2026). Application version: **v8.0.0.0**.

## Updated in this build

- Neutral wording throughout current source comments, SMART reports and
  documentation. Endurance details now say "model-specific endurance rule".
- Updated README with both current Light and Dark screenshots visible directly,
  using versioned image paths, plus current feature descriptions and limitations.
- Third-party copyright and the full MIT license notice remain in the source
  and installer. Device calculations and read-only commands are unchanged.

## Included disk and system-report features

- Select disks individually; inspect device SMART health, temperature, identity,
  firmware, NVMe counters and available ATA attributes. Original disk/volume
  information remains accessible in the overview.
- Total host reads/writes display decimal **TB**, with two decimal places, in
  the dashboard and Copy / Save TXT. Raw NVMe counters retain 128-bit precision.
- Read-only standard NVMe, ATA and USB SAT paths, targeted ASMedia ASM2362 and
  Realtek RTL9210 adapters, an identity-checked Intel RST path, and model-scoped
  SATA SSD endurance rules.
- Optional local IP/MAC addresses in System Report, hidden by default. The same
  selection controls Copy / Save TXT. No public-IP lookup is performed.

## Verification and limitations

- Latest checks: **4,558 regression assertions**, **307 English-only checks**,
  and **16 static report-export checks** passed; no Windows tweaks were applied.
- The disk-dashboard update previously passed **20,068 native UI assertions**.
  Read-only Native AOT probes read two NVMe SSDs and 27 ATA attributes from one
  USB drive. These earlier hardware checks are not new controller certification.
- Controller-specific RAID/USB additions and SATA vendor endurance rules have
  synthetic fixture coverage, not validation on matching hardware. VROC/VMD,
  AMD RAID, CSMI, hidden RAID-member enumeration, JMicron NVMe staging and Realtek
  dual-drive mode switching are not implemented.
- Missing health evidence remains Unknown. Endurance is estimated write wear,
  not years remaining or a guarantee against failure. Native Save dialogs were
  not exercised by static export checks.

See [Disk Info coverage](https://github.com/mnaufalalauddin/Naufal-Windows-Utility/blob/main/docs/disk-info.md)
and the attached changelog for details.

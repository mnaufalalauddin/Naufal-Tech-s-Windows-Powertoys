# Naufal Windows Utility v8.0.0.0 — Disk health and system reports

Build date: 28 September 2026. Application version: **v8.0.0.0**.

## Changes

- Added an individual-disk dashboard with device SMART health, temperature,
  identity, firmware, reliability counters and raw ATA attributes. Fixed disk
  selector labels intercepting clicks. The original disk/volume report remains
  available in the overview tab.
- Added native NVMe SMART/identify, ATA and USB SAT read-only paths. Health no
  longer substitutes Windows' generic disk status for device SMART evidence.
- Total host reads and writes now display decimal **TB** with two decimal places,
  including Copy / Save TXT. Raw 128-bit NVMe counters retain their precision.
- Added targeted ASMedia ASM2362, Realtek RTL9210 and Intel RST NVMe adapters,
  with identity checks and strict packet/completion validation.
- Added model-scoped SATA SSD endurance rules for selected Samsung,
  Intel/Solidigm, Crucial/Micron, Kingston and Kioxia/Toshiba families.
- Added optional local IP/MAC addresses to System Report. Hidden by default;
  the same selection controls display, Copy and Save TXT. No public-IP lookup.
- Updated README, report documentation, changelog and third-party notices.

## Verification and limitations

- 4,549 regression assertions, 20,068 native UI assertions, 307 English-only
  checks and 16 static report-export checks passed during this update.
- Read-only Native AOT probes read two real NVMe SSDs and 27 ATA attributes
  from a USB drive. No Windows tweaks or device writes were run in these probes.
- Controller-specific RAID/USB additions and SATA vendor endurance rules are
  tested with synthetic fixtures; matching hardware was unavailable. This is
  **not complete CrystalDiskInfo parity or hardware certification**.
- Missing data remains Unknown / Not reported. SSD endurance is estimated
  write wear, not years remaining or a guarantee against drive failure.
- VROC/VMD, AMD RAID, CSMI, hidden RAID-member enumeration, JMicron NVMe staging,
  and Realtek dual-drive mode switching are not implemented.
- Native Save dialogs were not exercised by the static export checks.

See [Disk Info coverage](https://github.com/mnaufalalauddin/Naufal-Windows-Utility/blob/main/docs/disk-info.md)
and the attached changelog for details.

## Download and installation

Download `Naufal-Windows-Utility-Setup-8.0.0.0-x64.exe` from this release's assets.
The automatically generated source archives are not ready-to-run installers.

- Targets Windows 10 / 11 x64; availability varies by Windows version and hardware.
- The installer is **unsigned**. Check its SHA-256 against `SHA256SUMS.txt`; do
  not disable security protection to run it.
- Close the application and finish active tasks before installing. Keep restore
  backups. If Setup detects an old installation in a different folder, follow
  its relocation instructions; do not manually delete backup folders.
- No settings are applied simply by downloading this release. Read each warning
  before running system-changing operations.

The dated build tag preserves earlier releases while keeping the requested
application version at v8.0.0.0.

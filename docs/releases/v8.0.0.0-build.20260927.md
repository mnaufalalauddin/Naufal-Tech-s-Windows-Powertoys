# Naufal Windows Utility v8.0.0.0

Release build: 27 September 2026.

## Changes

- Removed the standalone Reboot button from Home. About, Task Monitoring and
  Exit use a consistent responsive layout.
- Completed restart-sensitive tweaks now queue a shared Restart now / Later
  prompt. The prompt waits for active tasks, groups duplicate items and checks
  for new work after consent. Failed or unavailable tweaks do not trigger it.
  Choosing Later does not schedule a restart. No forced application termination.
- Apply and Restore use the same restart policy across catalogs. Profile BCD
  changes, successful runtime/driver restart flags and verified MSI changes
  also feed the queue; Explorer/app-only refresh settings are excluded.
- Standardized active app and installer metadata at 8.0.0.0, displayed as
  v8.0.0.0. Dependency versions and historical release records are unchanged.
- Updated repository branding/URLs to Naufal-Windows-Utility, the changelog and
  both maintainer-supplied Light/Dark README previews. Those screenshots still
  show the old Reboot button; their caption explains the difference.

## Download and installation

Download **Naufal-Windows-Utility-Setup-8.0.0.0-x64.exe** and **SHA256SUMS.txt**.
The Source code archives are development sources, not installers.

The installer is **unsigned**. Verify the source and SHA-256; do not disable
Windows protection just to launch it. Windows 10/11 x64 are intended targets;
not every Windows edition, build or hardware configuration has been validated.
Back up important data and read each tweak's warning before applying changes.

Default installation folder:
`C:\Program Files\Naufal Tech's Limited\Naufal Windows Utility`.

If an older installation remains registered in the Powertoys folder, close
the application and uninstall that version through Windows Settings before
installing this build. Setup does not automatically relocate/delete it.
Keep restore backups. The existing per-user data folder
`%LOCALAPPDATA%\Naufal Windows Powertoys` and upgrade identity are retained.

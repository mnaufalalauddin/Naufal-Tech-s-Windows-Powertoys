# Naufal Windows Utility v8.0.0.0 — Simplified UI Preview

**2 October 2026 · Development preview · Windows 10/11 x64 intended targets**

## Changes

- Analysis progress and expandable results now stay in the relevant catalog,
  runtime, GPU, MSI or BitLocker window. Report collection, action inventory and
  security evidence also use inline presentation instead of extra analysis windows.
- Long confirmation and message text wraps and scrolls. Apply/Cancel remain
  outside the scroll area so every warning can be read before proceeding.
- Removed Resource Analyzer, Background Owner Finder, Storage / Windows Servicing,
  Offline Image Workspace and standalone HVCI Enable/Disable/Restore controls.
  Historical module fixtures are test-only and excluded from the application build.
- HVCI status is read-only. The independent guarded LSA Enable control remains;
  Windows Security is available for reviewing Memory integrity settings.
- Retained Disk Info/SMART, system reports, repair tools, existing tweak/recovery
  backends, shared privacy snapshots and separate Apply/Restore progress.
- Updated README, changelog and current-versus-historical feature documentation.

Removal of a module does **not** delete user backups, change protection settings,
or modify offline images and virtual machines. Earlier release history is retained.

## Validation and limits

Regression evidence: 4,786 profile/action assertions, 337 English UI checks,
20,961 native WinUI assertions, 27 simplified-interface source checks, 92 catalog
interaction checks and 33 project-identity checks. Native UI coverage includes
128 layout cases, both themes, scaling, long confirmation scrolling and inline
error details. Native AOT x64 and Inno Setup packaging are checked separately.

This is a **pre-release**, not universal Windows/hardware certification. Live LSA,
driver and controller compatibility remain limited; passing UI/mock tests is not
proof of safe settings for every PC. No host tweak, security mutation, uninstall,
servicing operation or reboot is performed as part of publication checks.

## Download

Download `Naufal-Windows-Utility-Setup-8.0.0.0-x64.exe` and verify it against the
attached `SHA256SUMS.txt`. `CHANGELOG.md` contains the development history.
Close the previous application before installing. The installer is **unsigned**;
a matching checksum confirms file identity, not publisher trust. Keep backups
and review warnings before applying tweaks. GitHub's source archives are not
ready-to-run installers.
